ESPHome E-Ink Dashboard

Flash prebuilt firmware directly from your browser — no toolchain required.

  1. Connect your ESP32 board via USB
  2. Click Install below and select the serial port
  3. After flashing, configure Wi-Fi and Home Assistant via the ESPHome device portal
Requires a Chromium-based browser (Chrome or Edge) with Web Serial support. Firefox is not supported.
