# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively maintained.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/ziermmar/esphome-epaper-dashboard/security/advisories/new).

Include as much detail as possible:
- A description of the vulnerability and its potential impact
- Steps to reproduce or proof-of-concept
- Any suggested mitigations

You can expect an acknowledgement within 7 days. If the report is accepted, a fix will be prioritised and a public advisory published once a patch is available.
